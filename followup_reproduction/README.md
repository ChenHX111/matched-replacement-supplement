# Numerical follow-up artifact

This is a separate, anonymous **numerical replay**, not a training reproduction.
It requires only **CPython 3.11's standard library**; no installation, model,
dataset text, GPU, network access or external source workspace is required.
The tested interpreter version and actual checks are recorded in
`VERIFICATION.json`.

## Verify, regenerate, test

From this directory:

```text
python -B replay.py verify
python -B replay.py generate
python -B -m unittest discover -s tests -v
```

`verify` checks `MANIFEST.sha256`, all manifest-bound files, recomputes the
numeric outputs from scalar inputs, compares all accepted endpoint/stream
bindings, and requires generated bytes to reproduce. `generate` regenerates
only the distinct `generated/followup_*` outputs; it never writes outside this
artifact. Use `-B` to avoid creating untracked Python cache files.

For a clean replay, copy this directory elsewhere, remove **only that copy's
`generated` directory**, then run `generate` followed by `verify`. Commands
resolve inputs relative to the script, not a home directory or the original
working directory. The actual clean-relocation check is recorded in the handoff.

## What is independently reconstructed

The 120 complete background0/seed0,1,2 contexts supply:

- Original individual-effect vectors for all three seeds; the program derives
  each prediction seed's **other-two-seed**, same-background target.
- Supplied original G20 and difficulty vectors; primitive ALL_IN and new
  reference NLL projections; all four fixed G5 group/focal assignments; and
  the fixed donor's supplemental recipient readouts.
- Original ALL_OUT k4 uncovered counts, from which `1-uncovered_count/255`
  is derived without discarding its four-position structural offset.
- Accepted independent plain-gradient diagnostic score vectors, used only for
  rank/regret summaries, not calibrated loss-effect magnitudes.

From these, the program reconstructs reference scores, context endpoint
contrasts, complete ordered block populations, all **13 available
20,000-draw intervals**, their exact random-index streams, all-method
descriptive summaries, reference ladders and all available block/seed stability.
It is **not merely a replay from block summaries**. `inputs/EXPECTED.json`
contains accepted full-precision values only for checking; it is not passed
to the numerical computation.

### Boundary

Original individual effects/G20/difficulty and plain diagnostic scores are
supplied scalars, not recomputed from training or gradients. The artifact does
not re-tokenize text, regenerate masks/partitions/reference draws, verify
native model-state hashes, repeat qualification, or authenticate native
journals. The construction note and audit bind the frozen selected inputs.
Availability and cost records are accepted aggregate evidence, not independently
reconstructed timers. Unsanitized native archives remain outside this artifact;
their hashes and other source-origin identifiers are in
`inputs/SOURCE_ORIGINS.json`.

## Frozen statistical scope

The follow-up uses 24 main blocks and eight blocks per transport, background0,
and three seeds. Seed/context means are taken within block and blocks are
equally weighted. The root seed is **202610051754**; each endpoint uses the
frozen SHA256-based `stable_seed(root, endpoint_id)` and Python `random.Random`.
Each replicate draws n whole block indices with replacement. Percentiles use
linear interpolation at `(draws-1)*p`.

- Main: **eleven-test denominator retained**, two-sided level `1-.05/11`
  (approximately 99.545%). Five endpoints are numerical; six remain explicitly
  unavailable.
- IMDb/Pythia: all **11** authorized outcomes retained; five numerical,
  separately exploratory nominal95%.
- MultiEURLEX/GPT-2: all **7** authorized outcomes retained; three numerical,
  separately exploratory nominal95%.
- E02 keeps its frozen four-development/**twenty-evaluation** main-block
  population and denied development lock. All six configurations remain
  unavailable in the original tie order. Neither survivors nor evaluation
  winners are selected. Plain scores are not a substitute for qualified LoGra.
- All twenty E04 variants remain visible as unavailable; optional variants
  cannot rescue unqualified primaries. There are **two primary methods and
  four unavailable main contrasts**, not merely two comparisons.
- The older two-background, eleven-test/5,000-draw family and its numerical
  assets are separate and unchanged. This artifact does not regenerate them.

E01 companion error is **mean, not median**, absolute error. Q3 is the
within-eight-focal-context association defined precisely in `DEFINITIONS.md`;
it is not pooled across contexts, disjoint-reference support, or mediation.
Ties in top-two selection use focal order. Missing mandatory cells or undefined
ranks deny the whole corresponding endpoint, never a complete-case subset.

The matched-versus-role-disjoint Q1 contrast changes **all 768 reference rows:
748 background rows plus twenty matched controls**. It is not an isolated
background-information effect. Only the descriptive half-background reference
retains the twenty controls while replacing 374/748 background rows.
“Fresh” means eligibility relative to the selected P5 source identities and
duplicate groups, not absence from pretraining, P4 or all near-duplicates.

## Precision and checks

JSON and CSV sources preserve binary64 round-trip precision. TeX displays six
decimal places for readability. Full-precision estimates/intervals, input-cell
hashes, ordered-population hashes and stream hashes remain available in
`generated/followup_replayed.json`.

Verification permits at most `1e-14` absolute numerical discrepancy solely
for floating aggregation order. **Cell hashes, block order, seeds, all 20,000
draw streams, availability, signs and frozen decisions must match exactly.**
The actual maximum discrepancy on the tested interpreter is recorded in the
handoff; it was zero in the initial scalar replay. No interval, cutoff or
qualification gate is modified to pass verification.

Focused tests exercise other-seed targets, mean-versus-median error, tied
selection, mandatory G5 assignments, original support/within-context Q3,
undefined-rank denial, fixed original-block reuse, denied selection,
overlapping-time nulls, and the contrary selection seed exception.

## Generated assets

All new outputs have distinct `followup_` filenames and LF line endings.
There is **no mixed-unit forest plot**.

- `followup_main_endpoints.tex`: all five available and six unavailable main
  endpoints, with human-readable names and explicit units.
- `followup_main_summary.tex`: a compact four-decimal view of the five
  available main endpoints. Its paper caption must disclose the six unavailable
  contrasts and unchanged eleven-test denominator, and define the signed
  contrasts and distinct targets. The full table remains authoritative.
- `followup_imdb_endpoints.tex`, `followup_gpt2_endpoints.tex`: every authorized
  transport outcome, including unavailable comparisons.
- `followup_*_reference_methods.tex`: fixed reference-method summaries.
  Full CSVs also retain all unavailable methods/configurations.
- `followup_reference_ladder.*`, `followup_stability.*`: labelled descriptive
  data, not new intervals or tests. All **five available main endpoints** and
  all available transport endpoints are included. The stability table includes the positive
  seed0 E01 selection exception alongside negative seed1/seed2—not only
  favorable Q1/Q3 stability.
- `followup_all_projected_configurations.*`,
  `followup_unavailable_methods.tex`: full frozen comparator disclosure.
- `followup_costs.*`, `followup_cost_categories.csv`,
  `followup_qualification.csv`: fits/actions, qualification/failed costs
  and unresolved timing.
- `followup_input_feasibility.*`: outcome-free composition contrast ranges;
  the original two-background, main-only gate and executed background0
  assignments are kept separate. IMDb was ungated and its input contrast
  smaller. This is a design limitation, not an outcome-based explanation.

The TeX files are plain `tabular` fragments using standard LaTeX commands and
no new packages, captions, manuscript labels, font overrides or external paths.
They are data assets, not a compiled paper layout. “Unavailable” MAE for
difficulty/plain means their score magnitudes are not treated as calibrated
individual loss effects, not that their descriptive ranks are missing.

## Cost and qualification limitations

All **1,188 fits** are accepted (1,128 scientific +60 qualification), separately
from **1,532 actions** (1,300 accepted, 16 failed qualifications, 216 blocked
scientific stages). Six LoGra and ten E04 qualifications
failed; this is not a scientific null or comparator win.

`UNRESOLVED_SHARED_PLAIN_FINALIZER_OVERLAP` prevents an exact exclusive-science
total. Raw seconds, unaffected science subtotals, qualification and failed
costs remain separate; the ambiguous total stays null. The recorded six-worker
journal window includes launch skew/pauses and is not a synchronized elapsed
measurement or summed GPU-job time. No correction or new cost gate is inferred.
